# PFC1Roblox - Редизайн и починка вёрстки

## Структура файлов

### Папки ресурсов:
- **logos/** - Логотипы лиги
  - `pfcnewlogo.png` - Новый логотип PFC1 ROBLOX на красном градиенте
  - `default-driver.png` - Серый силуэт Roblox-человечка (заглушка для пилотов без фото)
  
- **fonts/** - Шрифты
  - `Entocentric-Regular.woff2` - Фирменный шрифт для названия лиги

### CSS файлы:
- **css/main.css** - Основная дизайн-система (CSS Variables, общие стили)
- **css/drivers.css** - Стили карточек пилотов в стиле F1

## Инструкция по установке шрифта Entocentric

1. Скачайте шрифт Entocentric Regular (можно найти на dafont.com или fontspace.com)
2. Конвертируйте в формат .woff2 (используйте online-convert.com или transfonter.org)
3. Поместите файл `Entocentric-Regular.woff2` в папку `fonts/`
4. Шрифт уже подключён в css/main.css через @font-face

## Изменения

### Все страницы теперь используют:
- Единую систему CSS переменных (:root)
- Острые углы (border-radius: 0) кроме карточек пилотов (8px)
- Шрифт Entocentric для логотипа
- Titillium Web для заголовков
- Inter для основного текста
- Roboto Mono для чисел и статистики

### Карточки пилотов (F1 стиль):
- Сетка: 4 в ряд на десктопе, 2 на планшете, 1 на мобильном
- Фото обрезается через object-fit: cover; object-position: center 20%
- При отсутствии фото показывается заглушка 👤
- Номер пилота в красном квадрате
- Статистика внизу карточки (очки, победы, подиумы, БК)
- Эффект наведения: scale(1.03) + тень

### Админ-панель:
- Тёмная тема с острыми углами
- Акцентный цвет изменён с синего на красный (#E10600)
- Добавлено поле загрузки фото пилота (URL)

## Как добавить фото пилота:
1. В админ-панели при создании/редактировании пилота вставьте URL изображения
2. Рекомендуется использовать изображения 1080x1420 или выше
3. Фото должно быть портретным, с головой и плечами пилота
4. Если фото нет - автоматически покажется серый силуэт

## Проверка работы:
1. Откройте public/drivers.html - проверьте сетку карточек
2. Откройте admin/index.html - проверьте форму добавления пилота
3. Все страницы должны иметь единый стиль
